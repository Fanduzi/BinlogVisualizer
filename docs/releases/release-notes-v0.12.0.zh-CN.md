# BinlogViz v0.12.0 发布说明

发布日期：2026-04-10

## 范围

`v0.12.0` 是一个以 compare / trend 变化解释层为核心主题的功能版本。

这个版本不改变现有分析链路和 workflow 能力边界，但让结果更容易直接使用。现在，compare 和 trend 会先给出主要负载变化驱动因素，再进入完整表格、模式列表和图表细节。

## 主要内容

- compare 报告新增 `key_findings`，会在详细的表、模式和操作类型分区之前先指出主要变化驱动因素
- trend 报告新增 `trend_summary`，会先总结上升模式、下降模式、表趋势、集中度变化和体量尖峰
- 新解释层已统一落到 `text`、`json`、`html` 三种输出
- 所有发现都保持为确定性、基于证据、最多 5 条，避免生成噪声式长文案
- 修正了 compare 在负向变化场景下的措辞，负载收缩现在会被正确描述为 decline，而不是 growth

## 兼容性说明

- 这个版本没有新增命令，也没有引入新的 parser 能力
- compare JSON 现在包含 `key_findings`
- trend JSON 现在包含 `trend_summary`
- 原有详细分区保持不变，并继续在新的摘要区块之后渲染

## 破坏性变更

无。
