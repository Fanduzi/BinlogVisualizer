# BinlogViz v0.10.1 发布说明

发布日期：2026-04-09

## 范围

`v0.10.1` 是建立在 `v0.10.0` 之上的一次补丁发布。这个版本不改变分析行为，只是把公开文档和安装说明同步到已经发布的 compare / trend 模式分析工作流上。

## 主要内容

- 更新 README 中的安装与下载示例，使其统一指向当前发布版本
- 让 README 里的工作流描述与已经上线的 `pattern_changes` 和 `pattern_trends` 能力保持一致
- 更新 landing page 的版本叙事，使当前版本徽标和时间线不再停留在 `v0.10.0`
- 保持 CLI reference 与安装说明和正式 release surface 一致

## 兼容性说明

- 这次补丁版本不涉及 CLI flags、报告契约或分析语义变化
- release assets、checksums 和安装示例现在统一引用 `v0.10.1`

## 破坏性变更

无。
