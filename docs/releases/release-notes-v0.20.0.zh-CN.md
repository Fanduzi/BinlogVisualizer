# BinlogViz v0.20.0 发布说明

发布日期：2026-04-20

## 范围

`v0.20.0` 加速发现模式的 binlog 探测，并改善多小时间隔分析窗口的文本报告可读性。

## 主要内容

- **快速探测**：发现模式（`--from-dir`）改为两阶段时间戳提取——首事件通过提前终止读取，末事件通过从文件尾部偏移解析——替代原有的全文件扫描。将"Resolved binlog files"输出前的等待从秒级降至亚秒级。
- **Sparkline 降采样**：文本报告活动概览的 sparkline 现在最多显示 50 个柱状条，并对数据点取桶内平均值。降采样时显示分辨率标注（如 `3 min/bar`），使数小时窗口下的概览保持可读。
- 新增 `OffsetParser` 接口支持基于偏移量的 binlog 解析。
