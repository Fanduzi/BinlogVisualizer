# BinlogViz v0.23.1 发布说明

发布日期：2026-08-30

## 概述

v0.23.1 是面向 MariaDB 值班场景的补丁版本。它恢复了连续 DDL GTID 文件的分析能力；这类文件在 v0.23.0 中会在生成报告前被拒绝。

## Bug 修复

- **连续 MariaDB DDL GTID 可正常分析（#61）**：每个由 GTID 开启的 DDL 组会在 DDL 的隐式边界结束，后续合法 GTID 会开启新组，不再报 `conflicting GTID`。
- **对象过滤仍保留 DDL 事务边界**：被排除的 DDL 仍会结束所属 GTID 组，但不会进入表、分钟、DDL 时间线或事务聚合。`--include-*` / `--exclude-*` 因此不会重新触发同一故障。
- **真实的事务内 GTID 冲突仍会失败**：显式事务的来源完整性校验保持不变；本补丁只调整隐式 DDL 边界。

## 破坏性变更

无。

## 兼容性说明

- CLI 参数、退出码、报告 schema、产物命名和支持平台均与 v0.23.0 保持一致。
- 位点、时间和 GTID 选择器仍按文档取交集。
