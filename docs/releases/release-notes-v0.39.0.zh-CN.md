# BinlogViz v0.39.0 发布说明

发布日期：2026-11-01

## 主要更新

- 工作流、快照、比较和趋势命令的人类可读消息，以及 compare 和 trend 文本报告，支持英文和简体中文。
- 远程 MySQL GTID 的规范文本以单个序号结尾时，保留不连续区间；MariaDB GTID 条目消失时，在建立复制连接前拒绝请求。

## 修复

- 安静模式和 JSON 错误模式下，工作流、快照和趋势的普通进度不再输出，警告和错误仍会保留。
- `version` 和根命令的 `-v` 会传递输出写入错误；清理错误不会覆盖此前的操作错误。

## 测试与 CI

- 新增 SQL 生成、凭据脱敏、JSON Schema 校验和流式生成列检查边界的回归测试。六个模糊测试目标覆盖解析器、远程读取、表达式、索引和 DDL，并保留对应回归用例。
- 在不禁用规则或放宽基线的前提下减少 lint 问题。
- CI 配置了独立的 MySQL 5.7.44 固定版本服务容器任务，运行 `TestFlashbackMySQL57DeprecatedMode`；跳过或缺少测试根级 PASS 均会失败。

## 兼容性

- 未新增 CLI 标志，JSON/schema 版本保持不变。
