# BinlogViz v0.4.0 发布说明

## 版本范围

`v0.4.0` 引入国际化（i18n）支持，允许用户以首选语言查看运行时输出。

这是一个向后兼容的功能版本，对分析结果模型和 CLI 接口没有破坏性变更。

## 主要功能

### 国际化（i18n）

BinlogViz 现在支持多种语言的运行时输出：

- **English** (`en`) - 默认
- **简体中文** (`zh-CN`)

### 语言切换

两种方式切换输出语言：

**命令行参数：**
```bash
binlogviz --lang zh-CN analyze mysql-bin.*
```

**环境变量：**
```bash
LANG=zh_CN.UTF-8 binlogviz analyze mysql-bin.*
```

### 本地化内容

以下输出已本地化：

- 错误消息（文件未找到、参数无效等）
- 报告章节（工作负载摘要、活跃表排行、大事务排行等）
- 报告标签（事务总数、持续时间等）
- 告警消息（大事务警告、写入尖峰检测）
- 进度提示（正在解析 binlog、正在完成分析等）

### 已知限制

命令帮助文本（`--help`）和 cobra 内置验证消息保持英文。这是 CLI 框架的限制，命令结构在编译时就已确定，早于语言偏好的获取。

## 运维须知

- `--lang` 参数优先级高于环境变量
- 如果指定了不支持的语言，工具会回退到英文
- 所有语言文件已嵌入二进制，无外部文件依赖

## 技术细节

- 使用 `github.com/nicksnyder/go-i18n/v2` 管理翻译
- 使用 `sync.RWMutex` 实现线程安全
- i18n 包测试覆盖率：85.9%
- 所有测试在启用竞态检测器的情况下通过

## 打包说明

- Release artifact 继续支持以下平台：
  - `darwin/amd64`
  - `darwin/arm64`
  - `linux/amd64`
  - `linux/arm64`
- 下载包含 checksum 校验文件
- 二进制文件大小增加：约 50KB（嵌入语言文件）
