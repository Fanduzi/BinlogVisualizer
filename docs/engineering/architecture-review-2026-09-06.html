parser 只抽字节 · Analyzer 消费 group

问题。 一个 group（GTID、XA、GTID 启动的 DDL）在 builder 里打开，在 normalize 里定类型，在 parser 里取身份，再被第二条 retain 谓词决定留不留。

做法。 一个 module 拥有 open / continue / close / ignore，以及完成后是否 retain；parser 只抽取字节。

  • locality：GTID 冲突只活在一个 module
  • leverage：下一段 XA 序列只改一张表
  • interface 就是测试面
  • retain 不再穿过 seam 泄漏
不与 ADR-0001 冲突。零行 XA group 被丢掉时，今天会变成 No-data result（exit 2）；加深后的 module 必须保住这条契约。
