# MySQL expression module

Generated-column checker and the CREATE/ALTER column parser. The schema catalog calls the parser. Flashback calls the checker. Neither imports this package's caller. See ADR 0007 and ADR 0012.

## Members

| File | Responsibility |
|------|----------------|
| `eval.go` | One grammar parsed once per expression into a cached tree, evaluated in the general domain (`EvalGenExpr`) or the exact-DECIMAL domain (`EvalDecExprInc`, a checked subset). |
| `expr.go` | Evaluates a schema-file generated expression against logged SQL literals: integer and DECIMAL arithmetic, `UPPER`/`LOWER`, `CONCAT`/`CONCAT_WS`, `LENGTH`/`CHAR_LENGTH`, and constant-path JSON extraction. Division uses MySQL's default 9-digit width, then rounds half away from zero to the column scale. An intermediate past 30 fractional digits or 65 digits of precision is not rounded to fit: a DECIMAL target is unverified, and an integer target rounds an exact product once. A mismatch names one example image. Printable text in a text charset is shown as text; binary and non-printable bytes stay hex. ENUM and SET values in that example use the schema-file member labels. An unmodelled charset or type is unverifiable, never a match and never a mismatch. A result outside the column type is unverifiable only when the logged value is the non-strict clip. TIME and DATETIME assignment rounds fractional seconds half away from zero to the column fsp, with a carry into the seconds unverified. A YEAR value coerced to text renders 4 digits ('0000' for YEAR 0). A fixed BINARY column zero-pads the expression result to its width. A _charset'..' quoted literal outside the dump-safe UTF family is not evaluated, since the dumped expression may have lost its bytes; a hex or binary literal names its bytes and is evaluated in any charset. Identical inputs with a different generated value are a mismatch even when the expression cannot be evaluated. |
| `assign.go` | The column-assignment half of generated-column checking: compares the evaluated value against the logged literal under the target type — integer bounds, BINARY zero-padding, TIME/DATETIME fraction rounding, CHAR padding, and the JSON member compare. Unmodelled assignment semantics (a non-strict truncation, a fraction carry into the seconds) are unverified. |
| `expr_json.go` | The JSON half of the value domain: constant-path extraction and unquote, and node-tree equality under MySQL's number handling (JSON numbers compare by value, -0 is 0, fixed-point when the literal is not a float). |
| `expr_decimal.go` | The exact-DECIMAL arithmetic: decimal.cc's 9-digit intermediate words, DIV and % over a rounded /, and half-away-from-zero assignment rounding to the column scale; past 30 fractional digits or 65 digits of precision a DECIMAL target is unverified and an integer target rounds an exact product once. |
| `schema.go` | `SchemaCol` and the column parser. Checks a column list against TABLE_MAP metadata: count, names, order, and types where the binlog has them. Integer `/` rounds half away from zero. |
| `scan.go` | `Scan` over CREATE/ALTER and schema-file text: dump segments, statements, and the words the catalog walker reads. mysql --batch newlines (`\n`) are whitespace. A backslash inside a quoted string stays inside that string. |
| `ident.go` | One identifier reader for DDL names. A doubled backtick or, under ANSI_QUOTES, a doubled double-quote is one character. A quoted name is not a keyword. An unquoted name may start with a digit (`2fa_codes`); a number or an exponent (`1e5`) does not. A versioned comment runs only when the server version is known and the comment's version is not newer; MySQL reads five digits (six from 8.1 when a space follows), MariaDB five or six. Otherwise it cannot be read. `AccountAfter` keeps a user account's quotes. |
| `droptable.go` | `ParseDropTable` reads a DROP TABLE name list with that reader (`IF EXISTS`, `TEMPORARY`, plain comments, versioned comments, ANSI_QUOTES). A MariaDB rewrite (`/* generated by server */`) does not take names from the preserved comment. Analyzer and flashback both call it. |
| `userlist.go` | `ParseDropUser` reads a DROP USER account list and `ParseRenameUser` a RENAME USER `old TO new` pair list, accounts keeping their quoted spelling. Analyzer and flashback both call them. |
| `renametable.go` | `ParseRenameTable` reads a RENAME TABLE `old TO new` pair list through the same identifier reader. Analyzer calls it; a quoted numeric-looking name is still a name. |

## Interfaces

| API | Contract |
|-----|----------|
| `EvalGenExpr`, `EvalDecExprInc` | One tree, two domains (ADR 0007). Callers do not touch the cached tree. |
| `SchemaCol` | One column type. `Name`, `Generated`, and `Expr` are exported. The other fields stay next to the parser. |
| `ParseSchemaColumns`, `CloneSchemaCols`, `ApplyTableCharset`, `AlterSlice`, `AlterNoColumnChange`, `GeneratedNameSet`, `ValidateSchemaRow`, `DumpSegments`, `DumpDatabase`, `SchemaColNames` | Column lists and schema-file text. |
| `PrepareGenImages`, `(*GenImages).Outcome`, `(*GenImages).DivIncrementFit`, `DivIncrementMismatch`, `DivIncrementHint`, `GeneratedMismatch`, `SQLTableName`, `UnverifiedGeneratedComment`, `UnverifiedGeneratedWarning` | Generated-column review. The caller passes logged images. |
| `NewScan`, `Scan` | The walker reads `Skip`, `Word`, `WordIs`, `Ident`, `Rest`, `UnreadWord`, `Qualified`, `ParenBody`, `PeekWord`, `PeekByte`, and the text and index `S` and `I`. |

## Dependencies

- Upstream: `internal/model` (`FlashbackWarning`, `FlashRow`) and `internal/i18n`.
- Downstream: `internal/schemacatalog`, `internal/flashback`, and `internal/analyzer`.
